# 傻逼面试

> 面试官一开口，答案就在这里。

一个 macOS 面试辅助桌面应用：听问题、出字幕、查你自己的资料、生成口语化回答，也能截图识题、解代码题。

- **免登录**：没有本软件账号体系，也不连任何“官方”后端。
- **自带 API**：问答、看图、语音转写、向量检索都走你自己配置的模型服务（OpenAI 兼容接口），费用由服务商收取。
- **数据在本机**：资料、会话、字幕存在本地 SQLite；API Key 用系统钥匙串加密保存。

[下载安装包](https://github.com/xiaobendaoke/ShaBiMianShi/releases) · [反馈问题](https://github.com/xiaobendaoke/ShaBiMianShi/issues)

## 功能

| 功能 | 说明 | 快捷键 |
|---|---|---|
| 🎙️ 语音听题 | 采集系统声音、麦克风或两者，自动分段转写，停顿后自动提交回答 | `⇧⌘G` |
| ✂️ 选区解题 | 框选题目截图交给图片模型，支持多张追加（最多 8 张），可选 C17 / C++ / Java / Python / JS / TS / Go | `⌥⌘X` |
| 📚 资料问答 | 导入简历、项目文档、笔记，关键词 + 向量混合检索，回答带出处 | — |
| 🪟 悬浮窗 | 独立置顶窗口显示答案，支持鼠标穿透、透明度、内容保护 | `⇧⌘Space` |
| 🔁 调整回答 | 再短一点 / 展开解释 / 重新回答；保留会话上下文与记忆 | — |

默认回答是**口语短答**：普通基础题直接回答，涉及个人经历的题目会检索资料；需要严格限制来源时选“仅依据资料”策略。

## 安装

目前只提供 **macOS Apple Silicon（M 系列）测试版**，最低 macOS 13。Intel Mac、Windows、Linux 暂无验证过的安装包。

1. 从 [Releases](https://github.com/xiaobendaoke/ShaBiMianShi/releases) 下载 `ShaBiMianShi-<版本>-mac-arm64.dmg`。
2. 把 **傻逼面试.app** 拖进“应用程序”。
3. 从“应用程序”打开。

安装包是临时签名，**没有 Apple Developer ID 签名和公证**，首次打开可能被拦截，需要到“系统设置 → 隐私与安全性”点“仍要打开”（[Apple 说明](https://support.apple.com/zh-cn/102445)）。之后会陆续请求以下权限：

- **钥匙串**：解密本机保存的 API Key。
- **麦克风**：用麦克风听题时。
- **屏幕录制 / 系统音频录制**：截图和采集系统声音时。授权后如提示，完整退出再打开。

## 五分钟上手

### 1. 配置模型

左侧 **模型与 API**，每一项填 Base URL、API Key、模型名，然后点 **保存**。

| 配置项 | 用途 | 要求 |
|---|---|---|
| 默认问答模型 | 文字问答、生成回答 | 支持流式对话 |
| 图片模型 | 截图识题、代码题 | 必须支持图片输入；默认与问答模型共用，可开“图片使用独立模型” |
| 语音转写（ASR） | 声音转文字 | 必须支持音频转写接口，普通聊天模型不行 |
| 向量服务 | 知识库语义检索 | 必须支持 embeddings；换模型后需要重建向量 |

保存后依次点 **测试服务 → 测试图片能力 → 测试真实音频**（用随包附带的 `resources/probes/` 夹具，会产生少量 API 调用费）。

先跑通最简单的一题：**新建面试**，输入“解释一下 TCP 三次握手”，能看到回答就说明问答链路正常。

### 2. 导入自己的资料

1. **知识库** → 新建或使用默认知识库。
2. **批量选择文件** 或 **导入文件夹**，支持 PDF / DOCX / Markdown / TXT。扫描版 PDF 没有文字层，会被标记为需要 OCR。
3. 等状态变成 **已就绪**，可以用“检索测试”看召回结果。
4. 回到 **面试辅助**，在右上角选择本次要用的知识库。

资料里写清楚**自己的职责、方案、结果和可核实的数字**，回答质量会好很多。模型仍可能出错，数字请自己核对。

### 3. 开始听题

1. 音源选择：线上面试选 **系统声音**，面对面练习选 **麦克风**，也可以两者都选（只有系统声音会触发自动回答）。
2. 点 **开始监听**，勾选 **自动回答**。
3. 自己作答时打开 **我正在说**（`⇧⌘M`），避免自己的话被当成问题。

这是**自动分段转写**，不是逐字实时字幕。生成回答时仍会继续收下一题，可用 `⌥⌘→` 立即切到下一题。

## 工作原理

```
系统声音 / 麦克风 ──► 分段 ──► ASR 转写 ──► 字幕（可编辑）
                                            │
截图 ──► 图片模型提取题目 ───────────────────┤
                                            ▼
                              问题 ──► 混合检索（关键词 + 向量）
                                            │  知识库 / 简历事实 / 会话记忆
                                            ▼
                                      问答模型流式生成
                                            │
                                 主窗口 ◄───┴───► 悬浮窗
```

- **系统声音**：`native/SystemAudio.swift` 编译出的小助手负责采集，主进程 `audioSession` 管理分段与转写重试。
- **文档入库**：解析（`parsers/`）→ 按章节切块（`chunker/`）→ 写入 SQLite → 建关键词索引和向量索引（`indexing/`），由 `ingestionQueue` 排队处理。
- **模型调用**：`providerService` 统一封装对话流、图片识题、语音转写、embeddings 和服务测试，全部指向你配置的端点。

## 从源码运行

需要 macOS、Node.js 22+；打包系统音频助手还需要 Xcode Command Line Tools（`swiftc`）。

```sh
git clone https://github.com/xiaobendaoke/ShaBiMianShi.git
cd ShaBiMianShi
npm ci
npm run dev          # 开发模式
```

```sh
npm run build        # 类型检查 + 构建
npm test             # 核心测试
npm run test:all     # 全部回归测试
npm run test:repair  # 修复安全 + 面试流程 + 生产回归
npm run bench        # 规模基准
```

```sh
npm run pack         # 打包 release/mac-arm64/傻逼面试.app（先完整退出正在运行的应用）
npm run dmg          # 生成 release/ 下的 DMG
```

`启动傻逼面试.command` 会用 Launch Services 打开最近一次 `pack` 出来的应用，这样系统权限会记在打包后的 App 上。

### 技术栈

Electron · React 19 · TypeScript · Vite · Tailwind CSS 4 · better-sqlite3 · pdf-parse · mammoth · lucide-react

界面固定为白色浅色主题，配色变量集中在 `src/renderer/src/index.css` 的 `:root`。

### 目录结构

```
src/
├── main/                  Electron 主进程
│   ├── index.ts           启动、IPC、快捷键
│   ├── windows/           主窗口与悬浮窗管理
│   ├── services/          模型调用、音频会话、入库队列、面试流程
│   ├── indexing/          关键词索引、向量索引、混合检索
│   ├── parsers/           PDF / DOCX / TXT 解析
│   ├── chunker/           文档切块
│   ├── db/                SQLite 存储
│   └── resources/         预置面试题库
├── preload/               渲染进程可用的安全 API
├── renderer/              React 界面
└── shared/                主进程与界面共享的类型和逻辑
native/                    系统音频采集助手（Swift）
resources/probes/          图片 / 语音能力测试夹具
scripts/                   打包、DMG、截图脚本
test/                      回归测试与合成夹具
docs/                      截图、依赖许可
personal/                  个人资料与备份（Git 忽略，不打包）
```

## 常见问题

| 问题 | 排查 |
|---|---|
| 文字问题没有回答 | 检查是否保存、Base URL、模型名、密钥和余额，先跑“测试服务” |
| 文字可以，截图不行 | 换支持图片输入的模型，跑“测试图片能力” |
| 听不到系统声音 | 确认电脑正在放声音、音源选对、系统音频权限已开，完整重启再试 |
| 麦克风没有字幕 | 检查麦克风权限、输入设备和音量，跑“测试真实音频” |
| 自己说的话被当成问题 | 打开“我正在说”，或只用系统声音触发 |
| 项目回答和资料对不上 | 检查选中的知识库、文档状态和检索结果；必要时用“仅依据资料” |
| 换模型后检索异常 | 重建对应配置的文档向量 |
| 更新后看不到旧资料 | 不要删库重建；确认同一个 macOS 账号，保留数据目录后提 issue |

提 issue 时请附上软件版本、macOS 版本、芯片、复现步骤和**脱敏后**的报错。不要上传 API Key、完整简历或本地数据库。

## 数据与隐私

- 数据目录：`~/Library/Application Support/面试狗-独立版/`（兼容旧版路径）。更新前建议备份，不要靠删除这个目录来“重装”。
- **本地保存 ≠ 离线处理**：问题、检索到的上下文、截图、语音片段和待向量化的文档内容，会按你启用的功能发给你配置的服务商。原始音频只在内存中短暂停留，转写后的字幕写入本地会话。
- 悬浮窗的内容保护在不同录屏 / 会议软件里效果不同，请自行验证，不保证一定不可见。

请遵守所在场景的录音、信息处理和工具使用规定。用于面试练习、模拟面试没问题；在真实面试中使用前，先确认对方是否允许。
