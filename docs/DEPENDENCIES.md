# 依赖许可与开源组件说明 (DEPENDENCIES.md)

本工程所采用的主要开源组件及许可说明：

| 模块 / 组件 | 许可证 | 作用与说明 |
|:---|:---|:---|
| **Electron** | MIT License | macOS 跨平台桌面应用外壳与原生窗口管理 |
| **React & React DOM** | MIT License | 响应式声明式前端 UI 渲染引擎 |
| **better-sqlite3** | MIT License | 本地 SQLite 3 嵌入式元数据与快照持久化引擎 |
| **Vite & Rollup** | MIT License | 极速前端与 Electron 多进程构建打包工具链 |
| **Tailwind CSS** | MIT License | 原子化现代前端样式工具 |
| **Lucide Icons** | ISC License | 矢量界面图标库 |
| **tsx / TypeScript** | Apache 2.0 / MIT | 静态类型安全系统与自动化测试执行器 |

所有依赖项均符合商业及个人本地开发友好之开源许可证。
